# Devlog – FastAPI Bookstore

## 2025-08-23

**What I did:**
- Expanded logging config to include DEBUG level for more detail.

- Added `sys.excepthook` to capture and log all uncaught exceptions.

- Experimented with filtering logging so that only container start/shutdown events are logged, ignoring FastAPI dev reload logs.
<br>
<br>

**What I learned:**
- `sys.excepthook` is a global safety net for crashes, ensuring exceptions don’t vanish silently.

- The `UVICORN_RUN_MAIN` variable can help detect the main process, but in Docker with reload enabled, it doesn’t perfectly distinguish reload vs container start.
<br>
<br>
