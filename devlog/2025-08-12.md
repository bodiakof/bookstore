# Devlog – FastAPI Bookstore

## 2025-08-12

**What I did:**
- Added BookFormat enum with three allowed values: PAPERBACK, HARDCOVER, EBOOK.

- Updated SQLAlchemy Book model with a new format column (String, NOT NULL, default "paperback").

- Updated Pydantic schemas to use BookFormat for type validation.

- Created app/enums folder for storing reusable enums.

- Added CRUD and API endpoint for filtering books by format (`GET /books/format/{format}`) with automatic validation.

- Updated CLI to allow setting book format on creation and enforced valid choices at CLI argument level.

- Fixed Alembic migration issue with SQLite by adding `server_default='paperback'` for the new column.
<br>
<br>
**What I learned:**
- `default=` in SQLAlchemy models only applies at the Python level, not in the DB schema — `server_default=` is needed for migrations to set values in existing rows.

- SQLite won’t let you add a NOT NULL column without either a default or a two-step migration.

- Using Enums in FastAPI not only validates incoming data but also improves API docs with dropdowns in Swagger UI.
<br>
<br>
**Next steps:**
- Consider adding more enums (e.g., Genre, Language) following the same pattern.

- Add an update book route that validates `BookFormat` changes.
