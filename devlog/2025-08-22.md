# Devlog – FastAPI Bookstore

## 2025-08-22

**What I did:**
- Removed Grafana, Loki, and Promtail from `docker-compose.yaml`.

- Implemented a global logging configuration in `app/core/logging_config.py`.

- Ensured logs are output both to console and file (`/app/logs/app.log`).

- Adjusted Docker Compose to mount `./logs` properly and run FastAPI container as a non-root user to prevent permission errors.

<br>
<br>

**What I learned:**
- Grafana/Loki/Promtail setup is overkill for a beginner project.

- Simple console + optional file logging is sufficient for early development.

- Python logging setup runs on import; you can use a “side-effect only” import to configure logging globally.

- Docker containers require correct UID/GID mapping for writing to host volumes.

- `logging.getLogger(__name__)` will automatically use the configuration if `logging_config` is imported once at startup.
